# Interfaces d'IaModelize3d

Captures du front React (`apps/repair-web/`), prises pendant les tests de bout en bout avec la démo sans clé
(`server/scripts/g1_demo.py`, IA simulée). Ordinateur en 1440 × 900, téléphone en 390 × 844.

L'interface est en **français et en anglais** : le sélecteur FR / EN est en haut à droite de chaque page. Les captures
en anglais sont plus bas.
